# Demo without pretending

## Two-minute practice walkthrough

1. Open Nerve and start Practice. Point out that the embedded view is a screenshot of a real isolated browser, not a decorative mockup.
2. Select Single switch. Use Space when Draft a reply is highlighted.
3. Select Confirm intent with the same switch. An exact action preview appears; the browser has not changed yet.
4. Approve the bounded steps with Space. Show the saved draft and the independently checked completion message. Nothing is sent.
5. Start another task and press Emergency stop. Old approvals cannot run. Resume only re-enables selection.
6. Show Session log and export. Explain exactly what was and was not recorded.

Practice is a deterministic integration test environment, not evidence of model reasoning. Do not describe its recipes as Astra-generated.

## Live Astra walkthrough

1. Configure an entitled key on the server. Select Connect Astra, explain screenshot sharing, and explicitly consent.
2. Leave the page blank to use the local synthetic workspace. Request Read this screen; these suggestions are generated by Astra.
3. Choose a goal and approve each concrete action. Narrate observable outcomes, not internal reasoning.
4. Try a correction or cancel. Stop remains reachable through the same input method.

Use no real account, payment, health, or credential data on stage. Provider errors should stay visible. A recorded fallback must be labeled recorded; practice is not a covert fallback for live failures.

## Optional camera segment

Ask before enabling a camera. Show nine calibration targets, then five held-out targets, then deliberate gesture calibration. If rejected, say it was rejected and use the switch. No lowering thresholds to create a successful-looking result. Gaze indicates attention; it does not prove intent. Session validation is an engineering check, not a clinical accuracy result.

## What to claim

- Minimal deliberate input can select an intent and authorize multiple assisted browser steps.
- Camera processing is local; screenshot sharing is separate and opt-in.
- The implementation separates inference, user selection, authorization, execution, and verification.
- Automated tests cover the behavior and safety boundaries described in the verification report.

## What not to claim

- Mind reading, medical-grade gaze, or universal accessibility.
- A demonstrated reduction in fatigue without a participant study.
- General control of every desktop app.
- That one successful demo establishes safety on arbitrary websites.
- That synthetic automated switch tests are trials with disabled users.
